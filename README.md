A chess implementation built with [p5.js](https://p5js.org/), rendered on an HTML canvas.

## Running

Open `index.html` in a browser (or serve the directory with any static file server).

## Features

- Full piece movement, captures, en passant, and check/checkmate/stalemate detection
- Pawn promotion picker
- Board theme toggle
